# Stammdaten

Die Stammdaten bilden die Grundlage für Realbau-Projekte.

## Aktuelle Quellen

- `LeitstellenspielFahrzeugtypen.xlsx`
- `LEitstellenspielAsubildungen.xlsx`
- `LeitstellenspielErweiterungen.xlsx`
- `Wachenbaukosten bis 10k.xlsx`

## Grundsatz

Die Fahrzeugtypen aus Leitstellenspiel werden als reale Fahrzeugklassen verwendet. Eine separate Tabelle für Realfahrzeugtypen wird nicht benötigt.

## Import-Ziel

Perspektivisch sollen Stammdaten über einen Importer aktualisiert werden können, ohne bestehende Planungsdaten zu löschen.

## Regeln

- Stammdaten dürfen referenzierbar bleiben.
- Anzeigenamen dürfen sich ändern, technische Schlüssel möglichst nicht.
- Neue Stammdaten werden hinzugefügt.
- Entfernte Stammdaten werden deaktiviert statt gelöscht.
