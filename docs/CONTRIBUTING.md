# Entwicklung

## Branches

- `main`: stabile Releases
- `develop`: aktive Entwicklung
- `feature/*`: einzelne Funktionen

## Commit-Stil

Beispiele:

```text
feat(api): add LSS session login service
feat(cache): implement JSON cache layer
docs: add architecture documentation
fix(auth): handle empty admin registration fields
```
